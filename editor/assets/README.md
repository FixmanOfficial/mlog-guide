# Ассеты из игры

## `ui.ttf` — основной шрифт интерфейса

Вырезка из `core/assets/fonts/font.woff` версии v159.7. Оригинал весит **3.5 МБ** и содержит
**42 515 глифов**, почти всё это иероглифы и письменности, которых на русско-английском сайте
не будет. Оставлены латиница, кириллица и знаки препинания — **344 глифа, 48 КБ**.

Снимает `tools/gen-font.mjs`: распаковывает WOFF, собирает нужные глифы вместе с частями составных
и перестраивает `glyf`, `loca`, `hmtx`, `cmap` и `maxp` под новую нумерацию. Разметка `GSUB`,
`GPOS`, `GDEF` и имена глифов выброшены, для отрисовки они не нужны.

Без этого шрифта редактор перестаёт быть похожим на редактор из игры — а он и есть главное,
ради чего всё это делается.

## `icon.ttf` — иконки интерфейса

`core/assets/fonts/icon.ttf`, 40 КБ, целиком.

Иконки в игре не спрайты: класс `Icon` генерируется по глифам этого шрифта, а имена глифов лежат
в его таблице `post`. Таблицу снимает `tools/gen-icons.mjs` в `core/data/icons.json`, так что для
отрисовки достаточно подключить шрифт и вывести символ по коду — 136 иконок без единой картинки.

## `mono.woff` — моноширинный

`core/assets/fonts/monospace.woff`. Это **Fira Code** под **SIL Open Font License 1.1**, 128 КБ.
Им набирается собранный текст программы.

## Лицензия

Всё это ассеты Mindustry под GPL-3.0 — та же лицензия, что у нас, поэтому использование законно.
Fira Code вдобавок под OFL. У основного шрифта в таблице `name` исходная гарнитура не названа,
копирайт заглушечный от fontello: если однажды выяснится, что там чужая гарнитура с несовместимой
лицензией, менять придётся именно `ui.ttf`.

# Ассеты из игры

## `icon.ttf`

Шрифт иконок интерфейса Mindustry, `core/assets/fonts/icon.ttf` версии v159.7, 40 КБ.

Иконки в игре не спрайты: класс `Icon` генерируется по глифам этого шрифта, а имена глифов лежат
в его таблице `post`. Таблицу снимает `tools/gen-icons.mjs` в `core/data/icons.json`, так что для
отрисовки достаточно подключить шрифт и вывести символ по коду — 136 иконок без единой картинки.

Рисунки иконок — собственная графика проекта Mindustry, лицензия GPL-3.0, та же, что у нас.
Fontello здесь только упаковщик, своего вклада в изображения не вносит.

## `mono.woff`

Моноширинный шрифт игры, `core/assets/fonts/monospace.woff`. Это **Fira Code** под
**SIL Open Font License 1.1**, 128 КБ. Лицензия своя и понятная, а шрифт при этом родной для игры.

## Чего здесь нет

Основной текстовый шрифт интерфейса, `font.woff`, сюда сознательно не копируется. Причин две,
и каждой хватило бы по отдельности:

- в его таблице `name` не названа исходная гарнитура, копирайт заглушечный от fontello;
- он весит **3.6 МБ** и содержит 42 515 глифов, включая иероглифы. Для страницы это неприемлемо
  в любом случае.

Подробности — в `docs/decisions.md`, раздел про шрифты.

# Журнал решений

Каждое принятое решение — строка здесь, с датой и причиной. Нужен, чтобы через месяц не
переспорить самого себя и не переоткрывать закрытые вопросы.

## 2026-09-04

### Название — mlog.guide

Аудитория ищет «mlog», а не бренд, поэтому имя = термин. Репозиторий `mlog-guide`, домен
`mlog.guide` (на момент решения свободен). Отвергнуты: «Гиперпроцессор», `@this`, «Млогбук».

Пока сайт на GitHub Pages — `base: /mlog-guide/`. При подключении домена `base` меняется на `/`
и добавляется `CNAME`.

### Пишем с нуля, источник — исходники игры

Существовал прототип от друга (`github.com/Durmiendo/milog`, VitePress + Vue, заброшен в августе
2026). Решено не продолжать его, а написать заново, сверяясь с Java-кодом Mindustry.

Причина: исходники игры — более авторитетный источник семантики, чем чужая JS-реализация. Плюс
снимается вопрос с лицензией на чужой код и появляется свобода в структуре курса.

### Лицензия — GPL-3.0

Mindustry под GPL-3.0. Наследуем ту же лицензию сознательно: это позволяет списывать из Java
напрямую, не занимаясь пересказом ради обхода копирайта. Точность важнее оригинальности.

### Версия игры — v159.7

Последний релизный тег. Зафиксирован жёстко: «сверяться с кодом игры» без пина — это сверяться
с движущейся мишенью. Обновление версии — отдельная задача с ревизией всех расхождений.

### Граница первой версии — 21 инструкция

Критерий: всё, что исполняется без симуляции карты и юнитов. Входят категории `io`, `operation`,
`control` целиком и `block` без `radar`.

Откладываются `radar`, вся категория `unit` и все 25 инструкций процессора мира — 32 штуки.
Без явной границы интерпретатор не выйдет никогда: хвост world-инструкций это половина
`LExecutor.java`.

### Стек — ядро на чистом JS, оболочка Astro + Starlight, остров Preact

Требование: сайт не должен есть сотни мегабайт, при том что внутри симуляция части игры.

Разбор причины: память едят не фреймворки (Vue runtime ~34 КБ), а DOM — сотни реактивных узлов
на юнитов. Отсюда два решения: мир рисуется в один `<canvas>`, а ядро не зависит от фреймворка
вообще, и потому выбор оболочки обратим.

Ванилла рассматривалась и отклонена: для документации пришлось бы вручную делать роутинг, поиск,
подсветку и сборку markdown, для редактора блоков — ручной DOM-диффинг. Astro отдаёт страницы
документации как статический HTML с нулём JS, песочница подключается островом.

### Песочница — детерминированная пошаговая симуляция

Не заглушки: `control` и `sensor` иначе нечем проверять. Фиксированный тик 60/сек, seeded RNG,
симуляция полностью отделена от рендера.

Даёт три вещи сразу: тесты гоняются в ноде без браузера, уроки проверяют состояние мира после N
тиков, бесплатно появляются пошаговый режим и перемотка.

Уровень детализации ограничен тем, что видно через `sensor`, `control` и `radar`. Предметы
и энергия — числа в здании; физики конвейеров, энергосети и крафта нет.

### Мультиязычность закладывается сразу

Домен `mlog.guide` планируется к покупке (~35 $, свободен), и держать на нём только русскую версию
не хочется. Инфраструктура делается симметричной с первого дня, переводы догоняют.

Русский — первый язык, английский — второй. Структура URL `/ru/...` и `/en/...` симметрична,
без «языка по умолчанию в корне»: так добавление третьего языка ничего не ломает.

Следствия для архитектуры:

- **Ядро не содержит текста для пользователя.** Ошибки интерпретатора возвращаются кодами
  и структурированными данными, строки собираются на стороне сайта. Это единственная часть,
  которую дорого чинить задним числом.
- **Имена инструкций, свойств и констант не переводятся** — `set`, `jump`, `@counter` это язык,
  а не интерфейс. Переводится объяснение вокруг них.
- **Урок переводится целиком, вместе с текстами проверок.** Сообщения проверок живут внутри
  локализованного урока, а не в отдельном словаре ключей: перевод урока это работа одного человека
  над одним файлом.

### Терминологию берём из бандлов игры

У Mindustry в `core/assets/bundles` лежат официальные переводы на 36 языков, и в них есть не только
названия блоков, но и вся терминология логики: 7 категорий с описаниями, 51 описание инструкций
(`lst.*`) и 113 описаний свойств `sensor`/`control` (`lenum.*`).

Значит документация может говорить ровно теми же словами, которые игрок видит в игре, а основа
перевода сайта на любой из 36 языков получается бесплатно. Снимает `tools/gen-bundles.mjs`.

### Библиотека arc пинится так же жёстко, как игра

Часть семантики mlog живёт не в Mindustry, а в arc: `Mathf`, `Angles`, `Rand`, `Simplex` и разбор
чисел. Mindustry закрепляет arc хешем коммита в `gradle.properties`, для v159.7 это
`archash=208a754044`. Берём тот же коммит.

Причина не формальная. Проверка показала три расхождения, которые видны прямо в mlog:
`@pi` это `float` `3.1415927`, а не число пи; `op angle result 1 0` возвращает `0.0000953`, потому
что `Mathf.atan2` — приближение полиномом; `1.5e3` вообще не число, а имя переменной, потому что
`Strings.parseDouble` проверяет дробную часть раньше экспоненты.

Угадать такое невозможно, а разойтись с игрой в учебнике по игре — худшее, что может случиться.
Перенос лежит в `core/src/arc.js` и правится только по исходнику.

# Детали семантики mlog

Каталог поведения, которое нельзя угадать — только вычитать в исходниках Mindustry **v160.3**.
Пути даны от `core/src/mindustry/`.

Правило: каждая строка отсюда закрывается тестом. Ссылаться на пункты по разделу и формулировке,
не по номеру — номера смещаются.

## Что изменилось в v160.2

Сборка вышла багфиксной, и языка почти не касается: одна инструкция считает координаты
по-другому, остальное — раскладка окна.

| Деталь | Источник | Тест |

## Исправленные заблуждения

Оставлено намеренно: эти утверждения выглядят правдоподобно и легко появляются снова.

| Неверно | На самом деле |
| --- | --- |
| «Логические идентификаторы зависят от порядка регистрации контента, поэтому дамп надо снимать с `content/*.java`» | Идентификаторы лежат в `logicids.dat` и стабильны между версиями. Парсить Java не нужно и вредно — получится другой порядок |
| «`end` возвращает счётчик на ноль» | `end` ставит счётчик за последнюю инструкцию; на ноль его переводит проверка границ в начале следующего шага |
| «`op angle result 1 0` вернёт ровно 0» | Вернёт `0.0000953`: `Mathf.atan2` это приближение полиномом, точное в кратных 45 градусам и ошибающееся на осях |
| «`@pi` это число пи» | Это `float` `3.1415927` из `Mathf`, расширенный до double |
| «`ucontrol move` отправляет юнита в точку» | Он записывает точку в контроллер. Пока команду повторяют, юнит к ней идёт; перестали — через 600 тиков он уходит своему ИИ |
| «Здоровье и дальность юнита можно списать из `UnitTypes.java`» | Здоровье — да, дальность — нет: она выводится в `init()` из скорости и времени жизни пуль каждого оружия |
| «Мягкие переходы между полами — это спрайты» | Это стенсиль, умноженный на текстуру пола при упаковке атласа. В `assets-raw` таких файлов нет вовсе |
| «Спрайты игры лежат в `assets-raw`, атлас — просто их упаковка» | Атлас содержит и то, чего в `assets-raw` нет: обводки юнитов, края полов, составные иконки блоков |
| «Варианты плиток выбираются случайно» | По координатам тайла. Случайность здесь была бы видна: карта мерцала бы при каждой перерисовке |

# Детали семантики mlog

Каталог поведения, которое нельзя угадать — только вычитать в исходниках Mindustry **v159.7**.
Пути даны от `core/src/mindustry/`.

Правило: каждая строка отсюда закрывается тестом. Ссылаться на пункты по разделу и формулировке,
не по номеру — номера смещаются.

## Исправленные заблуждения

Оставлено намеренно: эти утверждения выглядят правдоподобно и легко появляются снова.

| Неверно | На самом деле |
| --- | --- |
| «Логические идентификаторы зависят от порядка регистрации контента, поэтому дамп надо снимать с `content/*.java`» | Идентификаторы лежат в `logicids.dat` и стабильны между версиями. Парсить Java не нужно и вредно — получится другой порядок |
| «`end` возвращает счётчик на ноль» | `end` ставит счётчик за последнюю инструкцию; на ноль его переводит проверка границ в начале следующего шага |
| «`op angle result 1 0` вернёт ровно 0» | Вернёт `0.0000953`: `Mathf.atan2` это приближение полиномом, точное в кратных 45 градусам и ошибающееся на осях |

# Детали семантики mlog

Каталог поведения, которое нельзя угадать — только вычитать в исходниках Mindustry **v159.7**.
Пути даны от `core/src/mindustry/`.

Правило: каждая строка отсюда закрывается тестом. Ссылаться на пункты по разделу и формулировке,
не по номеру — номера смещаются.

## Библиотека arc

Mindustry закрепляет arc хешем коммита в `gradle.properties` — для v159.7 это `archash=208a754044`.
Разворачивать так же жёстко, как саму игру: `Mathf` и `Angles` меняются, и вместе с ними меняется
арифметика mlog.

| Деталь | Источник | Тест |
| --- | --- | --- |
| **`Mathf.PI` это `float` `3.1415927`, а не `Math.PI`.** Поэтому `@pi` в mlog равно `3.1415927410125732`, а `@radToDeg` — `57.2957763671875`. Расхождение с настоящим числом пи видно с седьмого знака | `arc/math/Mathf.java:11-21` | ✓ `arc.test.js` |
| **`Mathf.atan2` — полиномиальное приближение, а не точная функция.** Ошибка около `1.7e-6` радиан: `op angle result 1 0` возвращает не ноль, а `0.0000953`. При этом в кратных 45 градусам приближение попадает точно | `arc/math/Mathf.java` `atn` | ✓ `arc.test.js` |
| Для тригонометрии используются отдельные константы двойной точности `doubleDegRad` и `doubleRadDeg`, а не float-версии | `arc/math/Mathf.java:22-23` | ✓ `ops.test.js` |
| `Angles.angle(x, y)` считает направление вектора `(x, y)` и приводит к `[0, 360)`. Аргумент `x` идёт первым и в `Mathf.atan2` тоже | `arc/math/Angles.java:52-60` | ✓ `ops.test.js` |
| **`Strings.parseDouble` отбрасывает хвостовые `F`, `f` и точку**, поэтому `5f` и `5.` — числа | `arc/util/Strings.java` | ✓ `arc.test.js` |
| **Дробь с экспонентой числом не является.** Дробная часть проверяется раньше экспоненты, разбор `5e3` как целого проваливается, и `1.5e3` становится именем переменной. При этом `1e3` разбирается нормально | `arc/util/Strings.java` | ✓ `arc.test.js` |
| Переполнение при разборе числа даёт отказ разбора, а не бесконечность — токен превращается в имя переменной | `arc/util/Strings.java` `parseLong` | ✓ `arc.test.js` |

## Исправленные заблуждения

Оставлено намеренно: эти утверждения выглядят правдоподобно и легко появляются снова.

| Неверно | На самом деле |
| --- | --- |
| «Логические идентификаторы зависят от порядка регистрации контента, поэтому дамп надо снимать с `content/*.java`» | Идентификаторы лежат в `logicids.dat` и стабильны между версиями. Парсить Java не нужно и вредно — получится другой порядок |
| «`end` возвращает счётчик на ноль» | `end` ставит счётчик за последнюю инструкцию; на ноль его переводит проверка границ в начале следующего шага |
| «`op angle result 1 0` вернёт ровно 0» | Вернёт `0.0000953`: `Mathf.atan2` это приближение полиномом, точное в кратных 45 градусам и ошибающееся на осях |
| «`@pi` это число пи» | Это `float` `3.1415927` из `Mathf`, расширенный до double |

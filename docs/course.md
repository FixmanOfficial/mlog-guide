# Курс: полная опись уроков

Список всего, что должно быть написано, — по частям, категориям и группам. Порядок тот же,
что в курсе и в меню игры (`LCategory.all` и порядок меню «Добавить»); структура записана
в `web/src/course/parts.js`, здесь — её содержание.

Отметки: ✅ написан, ⏳ ждёт движка (см. границу симуляции в `docs/todo.md`), пусто — просто
не написан.

Правила, по которым этот список составлен, лежат в `docs/decisions.md`:

- **у каждой инструкции своя группа**, подписанная так, как её называет игра, и стоит она
  в той же категории, что и в меню «Добавить». Список групп не пишется руками: `parts.js`
  берёт его из снятой схемы целиком;
- группа без инструкции заводится только под введение части — как «Что это такое»
  у мирового процессора;
- тема, всплывающая больше чем в двух группах, живёт одним уроком: без чего нельзя начать —
  в «Основах», что нужно не всем и не сразу — в «Продвинутом»;
- урок объясняет свою инструкцию и ссылается на чужие, а не пересказывает их.

## Мировой процессор

Инструкций двадцать пять, и у каждой своя группа — как в меню «Добавить». Части нужна
и точка входа, поэтому первой стоит группа без инструкции.

| Группа | Уроки |
| --- | --- |
| Что это такое | ✅ откуда берётся, привилегии, скорость до 1000, невидимость для соседей |
| Query | ✅ поиск по области: круг и прямоугольник, список `@queries` |
| Get Block | ✅ что стоит в клетке: пол, руда, блок, здание |
| Set Block | ✅ поставить и снести, слои и усечение координат |
| Spawn Unit | ✅ создать юнита: поля, объект в ответ, чем ограничивать |
| Spawn Bullet | ✅ пуля из ниоткуда: чей патрон, чья команда, множители (юниты ⏳) |
| Apply Status | ✅ эффекты на юните: наложить и снять, таблица эффектов |
| Weather Sense | ✅ идёт ли погода: двоичный ответ, и он тоже привилегированный |
| Weather Set | ✅ включить погоду: шесть видов, и сама она не кончится |
| Spawn Wave | ✅ вызвать волну или высадить её состав (движок ⏳) |
| Set Rule | ✅ правила игры: множители, волны, `mapArea`, запреты |
| Flush Message | ✅ сообщение игроку: четыре вида, занятый экран и `@wait` |
| Cutscene | ✅ камера игрока: pan, zoom, stop, тряска (движок ⏳) |
| Effect | ✅ эффекты на карте: три десятка видов, размер и цвет (движок ⏳) |
| Explosion | ✅ взрыв в точке: чей он, радиус, убывание урона |
| Fetch | ✅ всё, что есть у команды: восемь видов, отбор и хрупкость номеров |
| Sync | ✅ разослать переменную: только на сервере, 20 раз в секунду |
| Client Data | ✅ данные в канал клиентам, надёжно или быстро |
| Get Flag | ✅ прочитать глобальный флаг, непоставленный флаг, перезапуск |
| Set Flag | ✅ поднять флаг, только «да»/«нет», связь с целями карты |
| Set Prop | ✅ свойства напрямую: здоровье, команда, запасы, мимо физики |
| Play Sound | ✅ звук: позиционный и глобальный, предел наложения (движок ⏳) |
| Play Music | ✅ музыка: прервать или дождаться (движок ⏳) |
| Set Marker | ✅ править метку: свойства, цвет, текст из буфера, где видно |
| Make Marker | ✅ создать метку: виды, номера, почему она живёт сама |
| Locale Print | ✅ текст из словаря карты, сборка ключа, пустой ответ |

| Урок | О чём |

## Особые случаи

| Что | Как решено |
| --- | --- |
| `noop` | единственная инструкция без группы: в схеме она помечена `invalid` — это не инструкция, а пустая строка, которую редактор подставляет вместо незнакомой. Разобрана в «Как писать в игре» |
| `getlink` и «Связи и getlink» | тема встречается дважды: в «Основах» — про связи вообще, потому что без них не работает ничего; в группе **Get Link** — про перебор по номеру. Второй урок ссылается на первый |
| Группы без уроков | пока в папке нет ни одного урока, группа не показывается ни в меню, ни на странице курса. Поэтому список можно держать полным, не боясь пустых разделов |

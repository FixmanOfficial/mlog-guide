# Курс: полная опись уроков

Список всего, что должно быть написано, — по частям, категориям и группам. Порядок тот же,
что в курсе и в меню игры (`LCategory.all` и порядок меню «Добавить»); структура записана
в `web/src/course/parts.js`, здесь — её содержание.

Отметки: ✅ написан, ⏳ ждёт движка (см. границу симуляции в `docs/todo.md`), пусто — просто
не написан.

Правила, по которым этот список составлен, лежат в `docs/decisions.md`:

- **у каждой инструкции своя группа**, подписанная так, как её называет игра, и стоит она
  в той же категории, что и в меню «Добавить». Список групп не пишется руками: `parts.js`
  берёт его из снятой схемы целиком;
- группа без инструкции заводится только под введение части — как «Что это такое»
  у мирового процессора;
- тема, всплывающая больше чем в двух группах, живёт одним уроком: без чего нельзя начать —
  в «Основах», что нужно не всем и не сразу — в «Продвинутом»;
- урок объясняет свою инструкцию и ссылается на чужие, а не пересказывает их.

## Мировой процессор

Инструкций двадцать пять, и у каждой своя группа — как в меню «Добавить». Части нужна
и точка входа, поэтому первой стоит группа без инструкции.

| Группа | Уроки |
| --- | --- |
| Что это такое | откуда берётся мировой процессор, чем отличается, почему обычный его не прочитает |
| Query | поиск юнитов по условию, `@queries` и чтение результата |
| Get Block | что стоит в клетке: пол, руда, стена, здание |
| Set Block | поставить и снести, усечение координат |
| Spawn Unit | появление юнита: команда, поворот, привязка |
| Spawn Bullet ⏳ | выстрел из ниоткуда: пули вне границы движка |
| Apply Status | эффекты на юните: наложить и снять, длительность |
| Weather Sense ⏳ | идёт ли погода |
| Weather Set ⏳ | включить и выключить погоду |
| Spawn Wave ⏳ | вызвать волну досрочно |
| Set Rule | правила партии: скорость, здоровье, дальность строительства |
| Flush Message | сообщение игроку из буфера печати, виды сообщений |
| Cutscene ⏳ | камера игрока: сдвиг, приближение, отпустить |

| Explosion ⏳ | взрыв в точке: урон, радиус, кому достанется |

## Продвинутое — поверх инструкций

| Урок | О чём |
| --- | --- |
| ✅ `@counter`: переход как значение | счётчик как переменная, вычисляемый переход |
| ✅ Число внутри | двойная точность, 53 бита, дроби, бесконечность |
| Время: `@time`, `@tick`, `@second` | из чего считаются, таймер на сроке |
| Сколько стоит инструкция | `@ipt`, что процессор успевает за тик |
| Упаковка данных | несколько чисел в одном, флаг юнита, распаковка |
| Несколько процессоров | разделение труда, кто кого ждёт |
| Чего не умеет редактор игры | внешние редакторы, длинные программы, перенос схемой |
| Тонкости языка | сравнение объектов, эпсилон в `equal`, `NaN`, порядок вычислений |

## Особые случаи

| Что | Как решено |
| --- | --- |
| `noop` | единственная инструкция без группы: в схеме она помечена `invalid` — это не инструкция, а пустая строка, которую редактор подставляет вместо незнакомой. Разобрана в «Как писать в игре» |
| `getlink` и «Связи и getlink» | тема встречается дважды: в «Основах» — про связи вообще, потому что без них не работает ничего; в группе **Get Link** — про перебор по номеру. Второй урок ссылается на первый |
| Группы без уроков | пока в папке нет ни одного урока, группа не показывается ни в меню, ни на странице курса. Поэтому список можно держать полным, не боясь пустых разделов |

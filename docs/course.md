# Курс: полная опись уроков

Список всего, что должно быть написано, — по частям, категориям и группам. Порядок тот же,
что в курсе и в меню игры (`LCategory.all` и порядок меню «Добавить»); структура записана
в `web/src/course/parts.js`, здесь — её содержание.

Отметки: ✅ написан, ⏳ ждёт движка (см. границу симуляции в `docs/todo.md`), пусто — просто
не написан.

Правила, по которым этот список составлен, лежат в `docs/decisions.md`:

- группа — это инструкция, подписанная так, как её называет игра;
- группа с другим названием заводится только там, где под одним именем разбирают семейство
  (`Мир`, `Цвет числом`);
- тема, всплывающая больше чем в двух группах, живёт одним уроком: без чего нельзя начать —
  в «Основах», что нужно не всем и не сразу — в «Продвинутом»;
- урок объясняет свою инструкцию и ссылается на чужие, а не пересказывает их.

Одна группа «Мир» на двадцать пять инструкций: поодиночке они не живут, а вместе делятся
на понятные темы.

| Урок | О чём |

## Продвинутое — поверх инструкций

| Урок | О чём |
| --- | --- |
| ✅ `@counter`: переход как значение | счётчик как переменная, вычисляемый переход |
| ✅ Число внутри | двойная точность, 53 бита, дроби, бесконечность |
| Время: `@time`, `@tick`, `@second` | из чего считаются, таймер на сроке |
| Сколько стоит инструкция | `@ipt`, что процессор успевает за тик |
| Упаковка данных | несколько чисел в одном, флаг юнита, распаковка |
| Несколько процессоров | разделение труда, кто кого ждёт |
| Чего не умеет редактор игры | внешние редакторы, длинные программы, перенос схемой |
| Тонкости языка | сравнение объектов, эпсилон в `equal`, `NaN`, порядок вычислений |

## Инструкции, у которых нет своей группы

| Инструкция | Где разобрана | Почему так |
| --- | --- | --- |
| `noop` | «Как писать в игре» | не инструкция, а пустая строка: появляется сама, когда блок неизвестен |
| `getlink` | своя группа **Get Link** плюс «Связи и getlink» в «Основах» | в «Основах» — про связи вообще, в группе — про перебор |
| `packcolor`, `unpackcolor` | группа **Цвет числом** | две инструкции об одном, и по отдельности им не хватает на урок |
| `setrate` | своя группа **Set Rate** | стоит в меню игры рядом с `wait`, и читатель будет искать её там |

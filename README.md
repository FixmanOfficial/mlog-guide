# mlog.guide

Интерактивный учебник и песочница по логике Mindustry (mlog), на русском.

Документация языка, интерпретатор и симуляция мира прямо на странице: код можно запускать,
шагать по инструкциям и смотреть, что происходит с блоками — не выходя из урока.

## Состояние

Ранняя разработка. Кода пока нет, есть план.

- [PLAN.md](PLAN.md) — опись инструкций, граница первой версии, модель песочницы
- [docs/decisions.md](docs/decisions.md) — журнал решений
- [docs/findings.md](docs/findings.md) — детали семантики mlog со ссылками на исходники игры

## Источник истины

Поведение языка сверяется с исходниками **Mindustry v160.4**, а не с документацией вики или
чужими реализациями. Тег зафиксирован; каждое найденное расхождение попадает в `docs/findings.md`
и закрывается тестом.

`draw color` берёт цвет четырьмя числами, и пока цвет в программе один — этого хватает.
Как только цветов становится несколько и их надо выбирать, четыре числа превращаются
в четыре переменные, которые всюду таскают вместе. `packcolor` складывает их в одну.

<Example client:load scene={PACK} world={true} />

```
packcolor красный 1 0 0 1
draw col красный
```

| Поле | Что в нём |
| --- | --- |
| первое | куда положить готовый цвет |
| остальные четыре | красный, зелёный, синий и прозрачность |

<Card kind="error">
**Каналы здесь от нуля до единицы, а не от нуля до 255.** У `draw color` они 0–255,
у `packcolor` — доли. `packcolor цвет 255 0 0 255` даст не красный, а белый: всё, что больше
единицы, прижимается к ней.
</Card>

## Цвет становится обычным значением

<Example client:load scene={CHOICE} world={true} />

Вот ради чего всё: цвет теперь **одно число**, а с одним числом можно делать то же, что
с любым другим. Положить в ячейку памяти. Выбрать через `select`. Передать в соседний
процессор. Здесь программа выбирает между тревожным и спокойным цветом одной строкой:

```
select цвет lessThan запас 50 тревога покой
draw col цвет
```

Через `draw color` то же самое потребовало бы ветвления и четырёх присваиваний в каждой ветке.

## Число, которое не надо читать

Загляните в таблицу переменных: у `красный` там не круглое значение, а что-то вроде
`2.1e-314`. Так и должно быть.

Упакованный цвет — это **байты цвета, положенные внутрь числа**, а не число в привычном
смысле. Для игры это просто способ провезти четыре байта в одном значении.

<Card kind="error">
**С упакованным цветом нельзя считать.** Сложить два цвета, взять от него половину, сравнить
«который ярче» — всё это даст бессмыслицу: складываются не цвета, а байты.

`print` тоже ничем не поможет: число настолько мало, что печатается нулём. Разобрать цвет
обратно на каналы умеет только <Lesson lesson="unpackcolor">`unpackcolor`</Lesson>.
</Card>

## Откуда ещё берутся такие числа

Свой цвет есть у предметов, жидкостей, блоков и команд, и `sensor` отдаёт его в том же
упакованном виде:

```
sensor цвет @copper @color
draw col цвет
```

Так на дисплее рисуют предмет его собственным цветом — не выписывая руками, что медь
рыжая.

<Card kind="recap">
- `packcolor результат r g b a` собирает цвет в одно число.
- Каналы — доли от нуля до единицы, а не 0–255.
- Готовый цвет дисплею отдаёт `draw col`.
- Цвет одним числом можно хранить, выбирать и передавать, как любое другое значение.
- Считать с ним нельзя: внутри байты, а не число.
- `sensor @color` отдаёт цвет в этом же виде.
</Card>

<Card kind="task">
Поменяйте в первом примере `packcolor красный 1 0 0 1` на `packcolor красный 255 0 0 255`
и запустите: квадрат станет белым — каналы больше единицы прижались к единице.

Потом во втором примере поставьте `set запас 70`: условие `lessThan запас 50` перестанет
выполняться, и `select` выдаст спокойный цвет вместо тревожного.
</Card>

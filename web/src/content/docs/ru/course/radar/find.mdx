На карте трое: кинжал и вспышка чужие, поли свой. Три радара находят разных — фильтрами.

## Поля инструкции

| Поле | Что в нём |
| --- | --- |
| первое, второе, третье | **фильтры**: три условия, которые складываются логическим И |
| четвёртое | чем мерить «лучшего» — об этом <Lesson lesson="radar/sort">следующий урок</Lesson> |
| пятое | **откуда смотрим**: блок, у которого спрашиваем |
| шестое | порядок сортировки |
| седьмое | куда положить найденного |

## Восемь фильтров

| Фильтр | Кто подходит |
| --- | --- |
| `any` | кто угодно |
| `enemy` | юнит чужой команды |
| `ally` | юнит своей команды |
| `flying` | летающий |
| `ground` | наземный |
| `attacker` | умеющий стрелять |
| `player` | под управлением игрока |
| `boss` | босс волны |

Заброшенная команда (`derelict`) чужой не считается: ржавые юниты на карте под `enemy`
не попадут.

Три фильтра — это **И**, а не ИЛИ: `enemy flying any` находит чужого **и** летящего.
Чтобы условий было меньше трёх, лишние ставят в `any`.

<Card kind="error">
**Радар не видит зданий.** Ни своих, ни чужих: он перебирает только юнитов. Чтобы найти
блок, у процессора есть связи (<Lesson lesson="getlink">`getlink`</Lesson>), а на карте —
мировые инструкции.
</Card>

## Откуда смотрит

Пятое поле — это блок, и дальность берётся у него:

| Блок | Насколько видит |
| --- | --- |
| турель | на дальность своей стрельбы |
| процессор | на дальность связи |
| остальные блоки | не видят вовсе |

Поэтому радар обычно вешают на ту самую турель, которой потом командуют: она видит ровно
то, до чего дострелит.

<Card kind="note">
Два фильтра в примерах курса не сработают никогда: `player` ищет юнита под управлением
игрока, а `boss` — вожака волны. Ни игроков, ни волн в песочнице нет, и ответом всегда
будет пустота. В самой игре они работают как обычно.
</Card>

<Card kind="recap">
- Радар ищет **одного** юнита: лучшего по мерке из четвёртого поля.
- Три фильтра складываются логическим И; ненужные ставят в `any`.
- Дальность берётся у блока, из которого смотрят.
- Зданий радар не находит вовсе.
</Card>

<Card kind="task">
Поменяйте в примере первый радар с `enemy any any` на `enemy ground any` — в `ближний`
попадёт кинжал, а вспышка выпадет: она летит.

Потом поставьте третьему радару `ally ground any`: ответом станет `null`. Поли — летающий,
других союзников на карте нет, и это не ошибка, а честный ответ «никого».
</Card>

`sensor` спрашивает про **конкретный** блок или юнита, которого программа уже держит
в переменной. Радар отвечает на другой вопрос: **кто рядом**.

```
radar enemy any any distance duo1 1 цель
```

Находит он ровно одного — «лучшего» по выбранной мерке, — и только **юнита**: зданий радар
не видит вовсе.

<Card kind="note">
Дальность у радара не своя: он смотрит настолько далеко, насколько видит блок, из которого
спрашивают. У турели это дальность стрельбы, у процессора — дальность связи.
</Card>

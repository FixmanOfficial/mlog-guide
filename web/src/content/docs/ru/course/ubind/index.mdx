Все инструкции про юнитов — `ucontrol`, `uradar`, `ulocate` — работают не с юнитом из поля,
а с тем, который лежит в `@unit`. Кладёт его туда `ubind`, и больше никто.

Отсюда весь порядок работы с юнитами: сначала привязать, потом командовать. Привязка живёт
до следующего `ubind`, своя у каждого процессора, и юнит о ней не знает — он просто начинает
слушаться.

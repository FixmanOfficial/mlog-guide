`sensor` и `control` — пара: первый читает свойство блока, второй его меняет. Читать можно
почти всё, а менять — ровно пять вещей:

| Свойство | Что делает | Кому |
| --- | --- | --- |
| `enabled` | включает и выключает блок | любому |
| `config` | меняет настройку — предмет, тип юнита | тем, кто настраивается контентом |
| `shoot` | стрелять по точке | турелям |
| `shootp` | стрелять по юниту с упреждением | турелям |
| `color` | цвет свечения | осветителю |

Больше ничего у блока изменить нельзя: ни запас, ни поворот, ни здоровье. Логика умеет
запускать и останавливать, а не строить и ломать.

<Card kind="error">
**Командовать можно только связанными блоками.** `control` проверяет связь с процессором,
и здание, добытое мимо неё — радаром, из ячейки памяти, у соседнего процессора, — команду
не выполнит. Ни ошибки, ни следа: строка просто ничего не сделает.

`sensor` при этом работает с кем угодно. Спрашивать можно любого, приказывать — только своим.
</Card>

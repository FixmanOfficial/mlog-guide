Третьим аргументом `sensor` берёт не только свойство, но и предмет. В хранилище 220 меди
и 15 графита; кремния нет вовсе, воды хранилище не держит в принципе.

<Example client:only="preact" scene={ITEMS} />

Три разных ответа на три похожих вопроса:

- **медь = 220** — предмет есть, вот сколько его;
- **кремний = 0** — предмет бывает, но здесь его нет;
- **вода = null** — хранилище не держит жидкости вовсе, спрашивать не о чем.

Ноль и `null` — не одно и то же. Ноль это ответ «нисколько». `null` — это «вопрос не про
меня».

## Пустота ведёт себя как ноль, пока её не поймать

Здесь начинаются грабли, на которые наступают все:

```
op equal a вода 0          # 1 — да, «равно»
op strictEqual b вода 0    # 0 — нет, не равно
op add c вода 1            # 1 — пустота посчиталась нулём
```

Обычное сравнение переводит `null` в число, а число у пустоты — ноль. Поэтому проверка
«в блоке ничего нет» ловит заодно и «блока нет», и «свойства нет», а программа продолжает
работать, только неправильно.

Отличить можно двумя способами:

```
op strictEqual пусто значение null
```

`strictEqual` сравнивает и значение, и тип, поэтому пустоту от нуля отличает. Второй способ —
сравнить с `null` напрямую: `op equal пусто значение null` тоже даст единицу, потому что оба
не число.

## Первый предмет — объект

`@firstItem` отдаёт не количество, а сам предмет: тот же объект, что константа `@copper`.
Его удобно передавать дальше — в `ucontrol itemTake`, в `sensor` следующим аргументом,
в `print`.

«Первый» — это тот, что лежит в блоке раньше других и ещё не кончился, а не самый крупный
и не первый по алфавиту. У бура это то, что он копает.

## Что можно спросить предметом

Любой предмет и любую жидкость из игры: `@copper`, `@graphite`, `@water`, `@cryofluid`.
Полный список — в [справочнике](/ru/reference/instructions/lookup/), там же способ перебрать
их все по номеру.

:::note
Жидкости в песочнице пока не текут: блоки, которые их хранят, всегда пустые. Числа
из примеров про предметы — настоящие, про жидкости — нет.
:::

## Задание

Нажмите «Править» и допишите к примеру две строки:

```
op equal кончилась кремний 0
op equal кончиласьВода вода 0
```

Обе покажут единицу. Первая права: кремния действительно нет. Вторая — нет: воду хранилище
не хранит вовсе, а проверка этого не заметила. Замените в ней `equal` на `strictEqual`
и посмотрите, как ответ станет честным.

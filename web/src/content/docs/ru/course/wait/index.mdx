По умолчанию процессор работает без остановки: выполнил свои инструкции за тик, на следующем
тике продолжил с того же места. Программа из трёх строк проходит итерацию несколько сотен раз
в секунду — и почти всегда это лишнее.

`wait` говорит «дальше не сейчас». Процессор отдаёт остаток тика и возвращается к той же
строке позже, когда время выйдет.

Соседи по категории делают похожее, но по-своему: [`end`](/ru/course/end/) начинает итерацию
заново, [`stop`](/ru/course/stop/) останавливает процессор совсем.

```
setflag "тревога" true
```

Нижний процессор через две секунды поднимает флаг, верхний его видит и печатает
предупреждение. Никакой связи между ними нет — только общее имя флага.

| Поле | Что в нём |
| --- | --- |
| первое | **имя флага**: строка, а не переменная |
| второе | значение: `true` или `false` |

## Флаг — это только «да» или «нет»

Значение у флага одно из двух. Положить в него число, предмет или юнита нельзя:
любое значение приводится к «истине» по тем же правилам, что в `jump` — ноль и пустота
ложны, всё остальное истинно.

```
setflag "волнаИдёт" 1        // истина
setflag "волнаИдёт" 0        // ложь
```

<Card kind="error">
**Имя флага — строка, и только строка.** Не `setflag тревога true`, а `setflag "тревога"
true`: без кавычек это переменная, и флаг просто не поднимется — молча, как всегда.

Зато имя можно собрать: переменная со строкой годится, и так делают именованные флаги
на каждого игрока или на каждую точку карты.
</Card>

## Чем флаг отличается от ячейки

| | Флаг | <Lesson lesson="write/shared">Ячейка памяти</Lesson> |
| --- | --- | --- |
| что хранит | «да» или «нет» | любые числа и объекты |
| сколько | сколько угодно имён | 64 или 512 мест |
| кто видит | любой процессор карты | только те, кто с ней связан |
| где живёт | в партии | в блоке на карте |
| кто ещё читает | **цели карты** | никто |

Последняя строка и есть главное. Флаги — общий язык мирового процессора и **целей карты**:
в редакторе есть условие «поднят такой-то флаг», и выполняется оно ровно по этому набору.

Поэтому сценарий обычно устроен так: процессор следит за происходящим и поднимает флаг,
а цель карты видит его и отмечает задание выполненным.

<Card kind="note">
Ячейку памяти надо поставить, к ней надо протянуть связь, и она ломается вместе со зданием.
Флагу ничего этого не нужно — он живёт в самой партии. Обратная сторона: в него не положить
ни числа, ни списка.
</Card>

<Card kind="recap">
- `setflag "имя" значение` поднимает или опускает флаг партии.
- Значение только двоичное: ноль и пустота — ложь, остальное — истина.
- Имя пишется строкой, в кавычках; можно собрать его из переменной.
- Флаги видны всем процессорам карты и целям в редакторе.
- Числа и объекты в флаг не положить — для этого есть ячейка памяти.
</Card>

<Card kind="task">
Поменяйте у нижнего процессора `setflag "тревога" true` на `setflag "тревога" false`:
верхний перестанет печатать предупреждение, хотя флаг по-прежнему «ставится».

Потом уберите кавычки — `setflag тревога true`. Ничего не сломается и ничего не произойдёт:
имя стало пустой переменной.
</Card>

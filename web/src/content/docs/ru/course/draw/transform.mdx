Повернуть прямоугольник командой `rect` нельзя — у неё нет поля поворота. Зато можно
повернуть **саму сетку**, в которой он рисуется.

<Example client:load scene={TRANSFORM} world={true} />

Три квадрата заданы одинаково, `40` на `40`. Первый нарисован как есть, второй — после сдвига
и поворота сетки, третий — после `reset`, снова в обычных координатах.

## Три команды и отмена

| Команда | Поля | Что делает |
| --- | --- | --- |
| `translate` | `x y` | сдвигает начало координат |
| `rotate` | `x y угол` | поворачивает сетку на угол в градусах |
| `scale` | `x y` | растягивает сетку по осям |
| `reset` | — | возвращает всё как было |

Они **накапливаются**: сдвиг после сдвига складывается, поворот после поворота тоже.
Отменяет их только `reset`.

<Card kind="note">
Масштаб считается шагами по 0.05, и единицей в этом счёте будет **20**:

| `draw scale` | Что выйдет |
| --- | --- |
| `20 20` | ничего не изменится |
| `40 40` | вдвое крупнее |
| `10 10` | вдвое мельче |

Поле целое, дробей в него писать не нужно — мелкость шага уже заложена.
</Card>

## Зачем это нужно

Повернуть фигуру иначе нельзя: у `rect`, `line` и `triangle` поворота нет вовсе,
а у `poly` он есть, но только вокруг её же середины. Сетка решает обе задачи:

```
draw translate 88 88
draw rotate 0 0 угол
draw rect -20 -20 40 40
draw reset
```

Квадрат нарисован **вокруг нуля** — от `-20` до `20`, — поэтому поворот крутит его вокруг
собственной середины, а `translate` ставит эту середину в центр дисплея. Стрелка компаса,
секундная стрелка часов, поворотная башня — все они устроены так.

<Card kind="error">
**Забытый `reset` портит следующую итерацию.** Сдвиги не сбрасываются сами: программа, которая
на каждой итерации делает `translate 88 88` и не отменяет его, на десятой итерации рисует
за краем дисплея — и выглядит это как «рисунок уехал и пропал».

Правило простое: сколько преобразований поставили, столько раз и `reset` — а лучше один
`reset` в начале итерации, сразу после `clear`.
</Card>

<Card kind="recap">
- `translate`, `rotate` и `scale` меняют систему координат, а не фигуру.
- Они накапливаются, и отменяет их только `reset`.
- Масштаб считается шагами по 0.05.
- Чтобы фигура крутилась вокруг себя, её рисуют вокруг нуля, а на место ставят сдвигом.
</Card>

Поменяйте в примере `draw rotate 0 0 45` на `draw rotate 0 0 10` и запустите: второй квадрат
почти выпрямится.

Потом уберите строку `draw reset`: третий квадрат — тот, что синий, — тоже уедет и повернётся,

</Card>

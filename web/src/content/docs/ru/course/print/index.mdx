`print` ничего не выводит. Он **дописывает** значение в текстовый буфер процессора — строку,
которая копится внутри и никому не видна, пока её не отдадут наружу.

Отдаёт её [`printflush`](/ru/course/printflush/) — в блок сообщений, или `draw print`
вместе с `drawflush` — на дисплей.

Из-за этого текст в mlog собирается по кусочкам: отдельно подпись, отдельно число, отдельно
разделитель. Склейки строк в языке нет вовсе, и она не нужна: буфер и есть склейка.

```
explosion @sharded 10 5 3 200 1 1 0 0
```

Один раз — и вражеского кинжала на клетке `10 5` больше нет: `врагов` падает с двух
до одного. Второй, который стоял в стороне, цел — радиус до него не дотянулся.

| Поле | Что в нём |
| --- | --- |
| первое | **чей взрыв**: его своим не заденет |
| второе и третье | точка в клетках |
| четвёртое | радиус в клетках |
| пятое | урон |
| шестое и седьмое | бить ли по воздуху и по земле |
| восьмое | пробивать ли: бить всех насквозь или только первого |
| девятое | показывать ли вспышку |

## Команда решает, кому больно

Первое поле — не «кого бить», а **чей это взрыв**. Пострадают все, кто не в этой команде.

```
explosion @sharded 10 5 3 200 1 1 0 0   # ваш взрыв, бьёт врагов
explosion @crux 10 5 3 200 1 1 0 0      # вражеский, бьёт вас
```

Перепутать легко, и ошибка получается тихая: программа исправно взрывает, а цель стоит
целёхонька — просто взрыв оказался «её собственный».

<Card kind="note">
Шестое и седьмое поле отделяют воздух от земли. Взрыв, которому велено бить только
по земле, не тронет ни вспышку, ни поли, — так делают наземные мины в сценариях.
</Card>

<Card kind="error">
**Урон убывает к краю радиуса.** В точке взрыва он полный, а у самой границы остаётся
около 40% — и только с включённым пробоем (восьмое поле) круг накрывает всех одинаково.

Поэтому «поставить радиус побольше» — не то же самое, что «ударить сильнее»: далёкий враг
получит свою долю и выживет.
</Card>

## Чем это пользуются

Взрыв — инструмент сценария, и нужен он там, где урон должен случиться **без причины**:

- ловушки и мины на карте: игрок наступил в запретную зону — взрыв;
- события: метеорит, обвал, диверсия;
- наказание за нарушение правила сценария — например, за постройку в запретной области;
- добивание: сценарий хочет, чтобы волна закончилась именно сейчас.

```
query circle unit @crux 10 5 3 0
sensor сколько @queries @size
jump 0 equal сколько 0
explosion @sharded 10 5 3 200 1 1 0 0
```

<Card kind="error">
**Взрыв бьёт и по зданиям тоже.** Радиус в три клетки посреди базы снесёт не только врага:
всё, что не вашей команды, получит урон — включая заброшенные постройки и стены.

Проверять, кто в радиусе, программа должна сама: <Lesson lesson="query">`query`</Lesson>
по той же области и по той же команде.
</Card>

<Card kind="recap">
- `explosion команда x y радиус урон воздух земля пробой вспышка` бьёт по площади.
- Первое поле — чей взрыв; своих он не задевает.
- Радиус и координаты в клетках, урон — обычное число.
- Воздух и земля отделены друг от друга.
- Здания в радиусе тоже получают урон.
</Card>

<Card kind="task">
Поменяйте в примере команду с `@sharded` на `@crux`: взрыв станет вражеским, и кинжалы
переживут его — `врагов` останется двойкой.

Потом верните `@sharded` и поставьте радиус `10`: второй кинжал тоже накроет, но он
переживёт удар — до него шесть клеток, и от двухсот урона доходит меньше четверти.
</Card>

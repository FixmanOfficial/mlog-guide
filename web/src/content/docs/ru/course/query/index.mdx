```
query circle unit null 9 6 3 0
sensor всего @queries @size
```

В круге радиусом три клетки вокруг точки `9 6` оказалось **три** юнита: два кинжала
и вспышка. Их список лежит в `@queries`.

| Поле | Что в нём |
| --- | --- |
| первое | форма: `circle` или `rect` |
| второе | что искать: `unit`, `building`, `bullet` |
| третье | команда или `null` — «чья угодно» |
| четвёртое и пятое | центр области в клетках |
| шестое | радиус у круга, ширина у прямоугольника |
| седьмое | высота у прямоугольника; кругу не нужна |

Прямоугольник считается **от центра**: `query rect unit null 9 6 4 4` — это квадрат
четыре на четыре клетки с серединой в `9 6`, а не угол в этой точке.

## Список читается как ячейка памяти

`@queries` — не число и не объект, а **список**. Работают с ним двумя инструкциями:

```
sensor сколько @queries @size
read кто @queries 0
```

`sensor @size` отдаёт длину, `read` — элемент по номеру, считая с нуля. Дальше каждый
элемент — обычный юнит или здание, у которого всё читается `sensor`.

Вот и весь перебор:

```
set номер 0
read кто @queries номер
sensor здоровье кто @health
op add номер номер 1
jump 1 lessThan номер сколько
```

<Card kind="error">
**Список живёт до следующего `query`.** Каждый поиск очищает `@queries` и заполняет заново —
свои списки в разных переменных так не сохранить. Нужно два набора разом — сначала перебирают
первый, потом делают второй запрос.

Это же значит, что между `query` и перебором не должно быть другого `query` — в том числе
в другой ветке программы.
</Card>

## Отбор по команде

Третье поле — команда, и оно решает, кого считать:

```
query circle unit null 9 6 3 0       // всех: трое
query circle unit @sharded 9 6 3 0   // только своих: двое
```

Пустота (`null`) означает «любая команда». Конкретная команда — только её юниты. Условия
«все, кроме моих» тут нет: если нужны именно враги, берут всех и отсеивают по `@team` сами.

<Card kind="note">
**Чем `query` отличается от `radar`.** Радар отдаёт **одного** — лучшего по сортировке,
и работает у любого процессора. `query` отдаёт **всех** и только у мирового; зато область
задаётся любая, а не дальность здания.
</Card>

<Card kind="recap">
- `query форма что команда x y ширина высота` собирает всех в области.
- Результат — список в `@queries`: длина через `sensor @size`, элементы через `read`.
- Прямоугольник считается от центра, круг — по радиусу.
- Команда `null` означает «любая».
- Каждый новый `query` затирает прошлый список.
</Card>

Процессор — такой же блок, как ячейка, и читается он так же. Только адресом служит не номер
места, а **имя переменной в кавычках**:

```
read чужиеИтерации processor1 "итераций"
```

<Example client:load scene={NEIGHBOUR} world={true} />

На карте два процессора. Верхний просто считает итерации; нижний — тот, чья программа
показана — достаёт его счётчик по имени и печатает. Ячейки между ними нет вовсе.

<Card kind="note">
«Шаг» двигает только показанный процессор, поэтому смотреть надо кнопкой «пуск»: верхнему
тоже нужно работать, иначе счётчику неоткуда расти.
</Card>

## Что может стоять адресом

| Адрес | Что получаем |
| --- | --- |
| `"итераций"` — у соседа есть такая переменная | её значение, число или объект |
| `"container1"` — переменной нет, но есть **связь** с этим именем | подключённое к соседу здание |
| `"чушь"` — нет ни того, ни другого | пустоту |
| `0`, `1`, … числом | связь соседа по номеру — то же, что его `getlink` |

Вторая строка примера как раз такая: `read чужойСклад processor1 "container1"`. Своей связи
со складом у нижнего процессора нет, а спросить у него запас меди он всё равно может —
здание берётся у соседа.

<Card kind="note">
Имя связи ищется только тогда, когда оно **кончается цифрой**: в игре перед поиском стоит
ровно такая быстрая проверка. Поэтому `"cell1"` сработает, а `"cell"` — нет.
</Card>

## И на себе тоже

`@this` — это сам процессор, и читать его можно тем же способом:

```
read копия @this "счёт"
read блок @this 0
```

Первое — копия собственной переменной, второе — собственная связь по номеру, то есть
`getlink` другими словами. Особой пользы в первом нет, а второе иногда удобнее.

## Мировой процессор так не прочитать

Привилегированный блок отвечает только привилегированному: обычный процессор, спросивший
мировой, получит пустоту. Это не про команду и не про связи — проверка стоит в самом блоке.

<Card kind="recap">
- Процессор читается как память, но адрес — имя переменной в кавычках.
- Нет такой переменной — отдаётся связь соседа с этим именем, если имя кончается цифрой.
- Адрес числом отдаёт связь соседа по номеру.
- `@this` читается тем же способом: своя переменная или своя связь.
- Мировой процессор обычному не отвечает.
</Card>

<Card kind="task">
Поменяйте в примере `"итераций"` на `"итерация"` и запустите: на табло появится `итераций null`.
Такой переменной у соседа нет, имя не кончается цифрой — значит, и связь искать негде.

Потом верните имя и поменяйте `"container1"` на `0` — надпись не изменится: у соседа одна
связь, и по номеру ноль это она же. А вот `1` даст `меди null`: связи под таким номером
у него нет, и спрашивать запас не у кого.
</Card>

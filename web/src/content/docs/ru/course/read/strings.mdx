Третий, кого умеет читать `read`, — обычная строка. Адрес здесь номер знака, а ответ — его
**код**, число:

```
read код "mlog" 0
```

В `код` окажется 109 — это `m`. Не буква, а именно число: отдельного вида «знак» в mlog
нет вовсе.

Программа проходит строку по знакам и складывает их обратно через `printchar`. На табло
появится `mlog` — та же строка, только собранная посимвольно.

## Зачем, если строку нельзя даже склеить

Строки в mlog почти неподвижны: их нельзя ни соединить, ни сравнить, ни обрезать. Единственное,
что с ними можно делать, — печатать целиком и разбирать по знакам. Отсюда и применения:

- **вывести текст по буквам** — бегущая строка на табло, буква за кругом;
- **разложить строку на коды и сложить их в память**, чтобы потом собрать в другом порядке;
- **достать один знак** из заготовленного набора: `read код "0123456789" цифра` превращает
  число в код его цифры.

<Card kind="note">
Обратная сторона — `printchar`: он берёт код и дописывает знак в буфер. `read` разбирает,
`printchar` собирает, и оба работают числами. Подробнее — в уроке

</Card>

## Границы те же, что у памяти

| Адрес | Что будет |
| --- | --- |
| `0` … длина минус один | код знака |
| длина и больше | пустота |
| отрицательный | пустота |
| дробный | усекается: `2.9` это знак 2 |

Длину строки узнать нечем — инструкции «сколько знаков» в языке нет. Поэтому цикл по строке
либо знает длину заранее, либо идёт до первой пустоты:

```
read код "mlog" номер
jump 5 strictEqual код null
printchar код
op add номер номер 1
jump 0 always
printflush message1
```

<Card kind="note">
Обычное сравнение `equal код 0` тут тоже сработает — пустота в нём равна нулю, — но говорит
оно о другом: «код равен нулю». Строгое (`===` в блоке, `strictEqual` в тексте) спрашивает
ровно то, что нужно: «знак есть или его нет вовсе».
</Card>

<Card kind="recap">
- `read` у строки отдаёт **код знака** по номеру, а не сам знак.
- Адреса те же, что у памяти: с нуля, дробный усекается, за границей пустота.
- Длину строки не спросить: цикл идёт до первой пустоты или знает её заранее.
- Собирает знаки обратно `printchar`.
</Card>

<Card kind="task">
Поменяйте в примере строку `"mlog"` на `"привет"` и число в переходе с `4` на `6`:
на табло появится `привет`. Кириллица читается так же — код просто больше.

Потом верните `"mlog"`, а в переходе оставьте `6`: в буфер уйдут два лишних знака, которых
в строке нет. Ничего не сломается — `printchar` пустоту пропускает молча, и надпись
останется прежней.
</Card>

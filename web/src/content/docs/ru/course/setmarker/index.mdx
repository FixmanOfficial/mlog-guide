```
setmarker color 1 %ff5555 0 0
setmarker radius 1 20 0 0
setmarker rotation 1 @time 0 0
```

Метка номер один краснеет, растёт и медленно крутится: последняя строка выполняется каждую
итерацию, и поворот идёт вслед за временем.

| Поле | Что в нём |
| --- | --- |
| первое | **что меняем**: свойство из списка |
| второе | номер метки |
| остальные три | значения — сколько нужно этому свойству |

## Свойств много, и у каждого вида свои

Список общий на все виды меток — два с лишним десятка свойств:

| Свойство | Что делает |
| --- | --- |
| `pos`, `endPos` | переставить метку; у линии — второй конец |
| `color`, `radius`, `stroke` | цвет, размер, толщина линии |
| `shape` | число сторон многоугольника |
| `rotation`, `arc` | поворот и дуга |
| `text`, `flushText`, `fontSize` | текст и его размер |
| `textAlign`, `lineAlign`, `labelFlags` | выравнивание, подложка и обводка подписи |
| `texture`, `textureSize` | картинка и её размер |
| `world`, `minimap`, `autoscale` | где метку видно и растёт ли она с приближением |
| `drawLayer` | порядок: что поверх чего |
| `remove` | убрать метку совсем |

<Card kind="note">
**Свойство, которого этот вид не понимает, просто игнорируется.** Радиус у текстовой метки,
поворот у точки — строка выполнится, и ничего не произойдёт. Это не ошибка, а устройство
инструкции: она одна на все виды.
</Card>

## Цвет и текст

Цвет пишут двумя способами: литералом `%ff5555` прямо в поле или упакованным числом
из <Lesson lesson="packcolor">`packcolor`</Lesson>. Второй способ нужен, когда цвет
считается — например, зелёный переходит в красный по мере убывания запаса.

Текст не задаётся значением — он **отдаётся из буфера печати**:

```
print "Строить здесь"
setmarker flushText 2 0 0 0
```

Тот же приём, что у `printflush` и `message`: собрали текст, отдали, буфер очистился.
Отсюда и удобство — в метку можно печатать числа и переменные, а не только строку.

<Card kind="error">
**Метка, которой не отдали текст, ничего не покажет.** Пустая текстовая метка на карте
не видна вовсе, и понять, что программа дошла до неё, нельзя. Проверять стоит по буферу
печати: если он не опустел, `flushText` не сработал.
</Card>

## Где метку видно

| Свойство | Что означает |
| --- | --- |
| `world` | рисовать на карте (по умолчанию да) |
| `minimap` | рисовать на миникарте |
| `autoscale` | уменьшаться при отдалении, чтобы не заслонять карту |

Метку можно вообще убрать с карты и оставить только на миникарте — так делают отметки
опасных зон, которые не должны мешать смотреть на базу.

<Card kind="recap">
- `setmarker свойство номер значения` настраивает уже созданную метку.
- Список свойств общий, и лишние для этого вида молча игнорируются.
- Цвет — литерал `%rrggbb` или упакованное число.
- Текст отдаётся из буфера печати через `flushText`.
- `remove` убирает метку, `world` и `minimap` решают, где её видно.
</Card>

<Card kind="task">
Поменяйте в примере `setmarker radius 1 20 0 0` на `setmarker shape 1 3 0 0`: круг станет
треугольником — это число сторон.

Потом добавьте строкой ниже `setmarker minimap 1 1 0 0`, а `world` выключите:
`setmarker world 1 0 0 0`. Метка пропадёт с карты примера — она осталась только
на миникарте, которой здесь нет.
</Card>

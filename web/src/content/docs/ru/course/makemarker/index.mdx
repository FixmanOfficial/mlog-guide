```
makemarker shape 1 8 7 1
makemarker text 2 8 3 1
makemarker line 3 4 5 1
```

Три метки: фигура, подпись и линия. Они появляются прямо на карте — не на дисплее,
а поверх мира, и видит их игрок.

| Поле | Что в нём |
| --- | --- |
| первое | вид метки |
| второе | **номер**: по нему её потом находят |
| третье и четвёртое | координаты в клетках |
| пятое | заменять ли метку с таким номером, если она уже есть |

## Метка живёт сама по себе

Это главное отличие от <Lesson lesson="draw/first">рисования на дисплее</Lesson>. Дисплей
надо перерисовывать каждый раз; метка поставлена один раз и остаётся на карте, пока
её не уберут.

```
setmarker remove 1 0 0 0
```

Отсюда и пятое поле: `makemarker` с тем же номером и `replace = 0` **ничего не сделает**,
если метка уже есть. Именно так её и ставят в цикле — программа зовёт `makemarker` каждую
итерацию, а метка от этого не плодится.

<Card kind="error">
**Номера метки не выдаются сами.** Их назначает программа, и если две части сценария
возьмут один номер, вторая молча затрёт первую.

Поэтому номера раздают заранее и по-крупному: у ловушек своя сотня, у подсказок своя.
</Card>

## Какие бывают

| Вид | Что рисует |
| --- | --- |
| `shape` | многоугольник: круг, треугольник, квадрат |
| `text` | текст на карте |
| `shapeText` | фигуру и подпись под ней |
| `line` | отрезок между двумя точками |
| `texture` | картинку — спрайт игры |
| `quad` | четырёхугольник по четырём углам |
| `point` | точку, видимую только на миникарте |

Все они настраиваются одной инструкцией — <Lesson lesson="setmarker">`setmarker`</Lesson>:
цвет, радиус, поворот, текст, слой рисования. Сразу после создания метка обычная: белый
четырёхугольник в заданной точке.

<Card kind="note">
Текст метки не задаётся в `makemarker`. Его печатают в буфер обычным `print`, а потом
отдают метке: `setmarker flushText 2 0 0 0` — тем же движением, что и `printflush`
в блок сообщений.
</Card>

<Card kind="recap">
- `makemarker вид номер x y заменять` ставит метку на карту.
- Метка живёт, пока её не уберут, — перерисовывать её не надо.
- Номер назначает программа; он же нужен для правки и удаления.
- Пятое поле защищает от повторного создания в цикле.
- Настраивают метку `setmarker`, а текст отдают через буфер печати.
</Card>

<Card kind="task">
Поменяйте в примере вид первой метки с `shape` на `shapeText`: над фигурой появится место
под подпись — правда, пустое, пока в неё не отдадут текст.

Потом поставьте пятому полю `makemarker text 2 8 3` ноль вместо единицы и подвиньте метку
на другие координаты: она останется на прежнем месте — с нулём замена не происходит.
</Card>

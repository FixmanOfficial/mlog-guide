`write` кладёт значение в память — ячейку или банк — по адресу. Обратная сторона
[`read`](/ru/course/read/), и поля у неё те же, только первое поле теперь не «куда положить
прочитанное», а «что записать».

Память нужна там, где не хватает переменных:

- **пережить правку программы.** Переменные обнуляются, когда программу меняют; память —
  нет;
- **поделиться с соседом.** Двум процессорам не видны переменные друг друга, зато ячейка
  видна обоим;
- **хранить список.** Переменная держит одно значение, ячейка — 64, банк — 512.

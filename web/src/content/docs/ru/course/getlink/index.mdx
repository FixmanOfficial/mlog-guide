Связь можно назвать по имени — `cell1`, `duo1`, — а можно взять **по номеру**. Номер это
порядок подключения: первый подключённый блок нулевой, второй первый и так далее.

<Example client:load scene={LOOP} world={true} />

Программа обходит все связи и печатает, что нашла: `container memory-cell message`. Имён
блоков она при этом не знает и знать не обязана.

## `@links` — сколько их всего

```
getlink блок номер
op add номер номер 1
jump 0 lessThan номер @links
```

`@links` — встроенная переменная процессора: число подключённых блоков. Именно ей заканчивают
цикл, а не числом: подключили ещё один блок — программа сама его увидит.

<Card kind="note">
`@links` — переменная, а не свойство: её читают как `@ipt` или `@time`, а не через `sensor`.
У `sensor` такого свойства нет вовсе.
</Card>

## За последней связью — пустота

<Example client:load scene={BEYOND} world={true} />

| Номер | Что вернёт |
| --- | --- |
| 0 и 1 | подключённые блоки |
| 2 при двух связях | `null` |
| `1.9` | связь номер 1: дробная часть отбрасывается |

Ошибки за границей нет — как и у памяти, ответом будет пустота.

## Зачем перебирать связи

- **Одна программа на разные базы.** Подключили шесть буров вместо трёх — цикл сам обойдёт
  шесть.
- **Поиск нужного блока.** Обходим связи, спрашиваем `@type` или `sensor`, находим тот,
  что искали.
- **Обход однотипных блоков.** Выключить все турели, опросить все склады, собрать сумму меди
  по всем контейнерам.

```
getlink блок номер
sensor тип блок @type
jump 7 notEqual тип @container
sensor меди блок @copper
op add всего всего меди
```

<Card kind="error">
**Порядок связей — это порядок подключения, а не расположение на карте.** Блок, подключённый
первым, останется нулевым, даже если стоит дальше всех. Перетасовать список нельзя:
отключить и подключить заново — единственный способ сменить номера.

Поэтому программы, полагающиеся на «нулевой блок это склад», ломаются молча, когда кто-то
переподключит связи.
</Card>

<Card kind="recap">
- `getlink переменная номер` берёт связь по порядку подключения, с нуля.
- `@links` — сколько связей у процессора; ей и заканчивают цикл.
- За последней связью лежит пустота, дробный номер усекается.
- Перебор связей позволяет писать программу, не зная заранее, что к ней подключат.
</Card>

```
cutscene pan 100 100 0.06 0
cutscene zoom 0.5 0 0 0
cutscene stop 0 0 0 0
```

| Действие | Что делает | Что в полях |
| --- | --- | --- |
| `pan` | ведёт камеру в точку | координаты в клетках и скорость |
| `zoom` | приближение | уровень от 0 до 1 |
| `stop` | вернуть камеру игроку | — |
| `shake` | тряхнуть экран | сила и длительность в секундах |
| `active` | идёт ли сейчас катсцена | куда положить ответ |
| `getHud`, `setHud` | виден ли интерфейс и показать ли его | ответ или значение |

## Камеру надо возвращать

Пока идёт катсцена, игрок **не управляет камерой**: она едет туда, куда её ведёт сценарий.
Это хорошо в кампании — показать, что происходит на другом конце карты, — и невыносимо,
если сценарий забыл её отпустить.

<Card kind="error">
**`stop` обязателен.** Ошибка в сценарии — и игрок остаётся без камеры до конца игры;
выйти из этого сам он не может. Поэтому катсцену ограничивают по времени
<Lesson lesson="advanced/time">таймером</Lesson> или флагом, а `stop` пишут первым делом.
</Card>

## Скорость и приближение

Скорость у `pan` — доля пути за тик: `0.06` даёт плавный подъезд, единица — мгновенный
скачок. Приближение — доля от полного: чем меньше число, тем дальше видно.

<Card kind="note">
**Инструкция работает у каждого игрока своя.** На сервере катсцена случается на экране
того, чей клиент её получил; на выделенном сервере без игроков она не делает ничего вовсе.
</Card>

<Card kind="error">
В песочнице курса камеры нет: пример всегда показывает карту целиком и не двигается.
Поэтому у `cutscene` здесь нет примера — в игре всё это работает.
</Card>

<Card kind="recap">
- `cutscene` управляет камерой игрока: `pan`, `zoom`, `shake`, `stop`.
- Пока идёт катсцена, игрок камерой не управляет.
- `stop` возвращает управление — без него игрок остаётся без камеры.
- `getHud` и `setHud` прячут и показывают интерфейс.
</Card>

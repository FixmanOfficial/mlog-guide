```
weatherset @rain true
```

Через две секунды мировой процессор включает дождь и тут же проверяет себя
<Lesson lesson="weathersense">`weathersense`</Lesson>: на табло появляется `дождь: 1`.

| Поле | Что в нём |
| --- | --- |
| первое | вид погоды: `@rain`, `@snowing`, `@sandstorm`, `@sporestorm`, `@fog` |
| второе | включить или выключить |

## Шесть видов

| Константа | Что это |
| --- | --- |
| `@rain` | дождь |
| `@snowing` | снег |
| `@sandstorm` | песчаная буря |
| `@sporestorm` | споровая буря |
| `@fog` | туман |
| `@suspend-particles` | висящие в воздухе частицы |

Имена берутся у самого контента, и совпадают они не всегда с тем, что ждёшь: снег
называется `@snowing`, а не `@snow`.

<Card kind="note">
Погода — не только картинка. В игре она мешает: буря бьёт по юнитам, споры отравляют,
туман закрывает обзор. Поэтому включение погоды в сценарии — это осложнение, а не украшение.
</Card>

## Погода включается насовсем

<Card kind="error">
Включённая логикой погода **не кончается сама**. Обычная погода на карте приходит
и уходит по своему сроку, а поставленная `weatherset` держится, пока её не выключат:

```
weatherset @sandstorm false
```

Поэтому сценарий, включивший бурю на минуту, обязан сам её и снять — по
<Lesson lesson="advanced/time">таймеру</Lesson>, флагу или событию.
</Card>

<Card kind="note">
**В песочнице курса погоды не видно.** Модель знает, идёт она или нет, — этого хватает
инструкциям, — но частиц и урона от неё здесь нет. В игре всё это есть.
</Card>

<Card kind="recap">
- `weatherset вид включить` управляет погодой на карте.
- Видов шесть; имена — константы контента, `@snowing` вместо `@snow`.
- Включённая логикой погода сама не прекращается.
- Инструкция привилегированная: только мировой процессор.
</Card>

<Card kind="task">
Поменяйте в примере `@rain` на `@sandstorm` в строке `weatherset`: табло перестанет
показывать дождь — идёт другая погода, а спрашивают про дождь.

Потом допишите `print буря` после `print дождь`: буря окажется единицей, а дождь нулём.
</Card>

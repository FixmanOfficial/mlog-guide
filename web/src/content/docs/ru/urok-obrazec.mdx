Страница-образец: так урок будет вставлять песочницу. Она здесь строже, чем на своей странице —
править можно программу одного процессора, набор инструкций сужен до тех, о которых уже
рассказано, строить и перематывать время нельзя.

Кроме прав урок передаёт своё описание сцены, ключ хранилища — под ним запоминается программа
ученика — и обработчик, который сработает, когда выполнены все цели карты:

```jsx
<Sandbox
    client:only="preact"
    scene={LESSON}
    storage="urok-obrazec"
    allow={{
        edit: ['processor1'],
        instructions: ['set', 'op', 'print', 'printflush', 'setflag'],
        build: false,
        time: false
    }}
/>
```

Когда все цели выполнены, песочница шлёт в окно событие `mlog:done`. Событие, а не функция
в пропсах: остров на странице Astro получает пропсы разобранными из JSON, и функцию туда
не передать.

```html
<script>
    addEventListener('mlog:done', () => console.log('задание сделано'))
</script>
```

Сцена — обычные данные: карта строками, блоки списком, цели видами. Здесь она крохотная:
процессор мира, блок сообщений и одна цель, которая ждёт флага. Чтобы её закрыть, допишите
в программу `setflag "готово" true`.

<Sandbox

    }}
